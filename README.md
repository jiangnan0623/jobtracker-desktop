# 个人求职助手

个人求职助手是一款本地运行的桌面端求职进度管理工具，用于管理岗位投递、招聘流程、简历文件、面试记录、笔记资料和日程事项。

项目面向秋招、春招、实习、提前批、社招、国企、银行、研究所等求职场景，重点解决“投了什么、进展到哪、用的是哪份简历、后续什么时候处理”的问题。

## 项目特点

- 本地桌面客户端，数据默认保存在用户电脑中。
- 支持投递记录全流程管理：岗位信息、投递状态、招聘流程、面试记录、JD、备注。
- 支持简历文件管理、投递绑定简历、查看简历被哪些投递记录使用。
- 支持新增投递时临时上传简历并自动绑定。
- 支持独立笔记管理，提供 Markdown、TXT、PDF、Word 文件预览和管理。
- 支持日程管理，可按月、周、日、列表视图查看待办事项。
- 支持未完成日程全局预警，并可快速查看未完成或紧急日程。
- 支持投递详情关联日程，方便查看某个岗位相关的笔试、面试、复盘或截止事项。

## 技术架构

桌面端采用：

- Electron：桌面窗口和本地进程管理
- Vue 3 + TypeScript + Element Plus：前端界面
- Spring Boot 3：本地后端服务
- MyBatis Plus：数据访问层
- H2：桌面端本地文件数据库
- 本地文件系统：保存简历、面试笔记、普通笔记和上传文件

运行方式：

```text
Electron 客户端
   ↓ 启动本地后端服务
Spring Boot 后端 127.0.0.1:18080
   ↓
H2 本地数据库 + 本地文件目录
```

桌面端启动后会自动启动本地后端服务，并打开客户端窗口。用户通常不需要手动启动前端或后端。

## 核心功能

### Dashboard

- 查看总投递数、面试数、Offer 数。
- 查看投递状态分布、每周投递趋势和公司投递统计。
- 查看最近投递记录。
- 查看今日日程，快速关注当天待处理事项。

### 投递管理

- 新增、编辑、删除投递记录。
- 支持岗位类别、简历类别多选和自定义。
- 支持投递批次、投递状态自定义。
- 支持绑定已有简历。
- 支持新增投递时临时上传简历并自动绑定。
- 支持 Markdown 岗位 JD。
- 支持按公司名、状态、岗位类别、投递批次、简历类别、投递时间范围查询。
- 支持按投递时间和公司名排序。
- 支持按公司合并展示。

### 投递详情

- 查看岗位基础信息、来源、链接、地点、薪资、备注。
- 预览绑定的 PDF 简历。
- 渲染展示岗位 JD。
- 以时间轴展示投递进度。
- 支持自定义招聘流程。
- 支持在节点旁就地编辑进度、结果和操作时间。
- 支持每个流程节点独立保存时间，并校验节点时间顺序。
- 支持 Offer 和淘汰作为最终结果处理。
- 支持查看与当前投递关联的日程。
- 支持面试记录和面试复盘笔记管理。
- 页面分区可折叠展开，减少长页面占用空间。

### 简历管理

- 上传简历文件。
- 编辑版本名称和备注。
- PDF 简历预览。
- 下载和删除简历。
- 查看每份简历被多少个投递项目绑定。
- 通过弹窗查看某份简历关联的具体投递记录。

### 笔记管理

笔记管理是独立于岗位面试笔记的普通笔记区，类似一个轻量文件管理器。

支持：

- 新建文件夹。
- 新建笔记。
- 上传笔记。
- 编辑文件信息。
- 拖拽移动文件夹和笔记。
- 移出到根目录。
- 下载文件。
- 删除文件或文件夹。

支持文件类型：

| 类型 | 预览 | 编辑内容 |
| --- | --- | --- |
| `.md` / `.markdown` | 支持 | 支持 |
| `.txt` | 支持 | 支持 |
| `.pdf` | 支持 | 不支持 |
| `.doc` / `.docx` | 支持提取文本预览 | 不支持 |

PDF 和 Word 文件不能直接编辑正文，但可以编辑名称、所在位置等文件信息。

### 日程管理

- 支持新增、编辑、完成、取消、删除日程。
- 支持月视图、周视图、日视图和列表视图。
- 支持选择查看的月份、周或日期。
- 支持日程起止时间，精确到分钟。
- 支持预定义颜色标识优先级和重要程度。
- 支持快速查看今日、本周、本月、未完成、紧急日程。
- 已取消日程不计入未完成预警。
- 支持将日程关联到具体投递记录。

### 系统设置

支持可视化设置本地保存位置：

- 简历保存目录
- 面试笔记保存目录
- 普通笔记保存目录

修改保存位置后，新上传或新创建的文件会保存到新的目录；已有文件不会自动迁移。

## 用户数据

桌面端默认使用系统应用数据目录保存数据，例如：

```text
C:\Users\用户名\AppData\Roaming\个人求职助手\
```

通常包含：

```text
jobtracker.mv.db          H2 本地数据库
resumes\                  简历文件
interview_notes\          岗位详情里的面试笔记
notes\                    普通笔记文件
storage.properties        保存目录配置
```

如果用户在系统设置中修改了保存目录，新文件会保存到新的自定义目录。已有文件不会自动迁移。

## 本地开发运行

开发环境建议：

- Windows 10 / Windows 11
- Java 17 JDK
- Maven 3.9+
- Node.js / npm

后端开发运行：

```powershell
cd <PROJECT_ROOT>\backend
mvn spring-boot:run
```

前端开发运行：

```powershell
cd <PROJECT_ROOT>\frontend
npm.cmd install
npm.cmd run dev
```

前端默认地址：

```text
http://localhost:5173
```

后端默认地址：

```text
http://localhost:8080
```

## 注意事项

- 桌面版默认本地运行，数据不会主动上传到服务器。
- 修改保存位置只影响新文件，不自动迁移旧文件。
- 删除文件夹会同时删除其子项目，请谨慎操作。
- 删除简历前建议先查看该简历是否已绑定投递记录。
- 已取消日程不会计入未完成预警。
